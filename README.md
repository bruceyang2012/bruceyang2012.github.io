# Bruce Yang Personal Blog

一个适合 GitHub Pages 的零依赖个人博客首页。

## 本地预览

直接打开 `index.html`，或用任意静态服务器托管当前目录。

## 部署

将 `index.html`、`styles.css`、`script.js` 推送到 `bruceyang2012.github.io` 仓库根目录即可。

## 在线编辑

站点页面右下角提供“编辑此页”入口，会打开 GitHub Web Editor。

- 修改内容后在 GitHub 页面底部填写提交说明并提交到 `master`
- GitHub Pages 会自动刷新线上站点
- 旧文章页仍是静态 HTML，编辑时请保留页面头尾的样式和脚本引用
